# Кастомизация блога

Приложение на React и TypeScript с панелью настройки статьи. В форме можно выбрать шрифт, размер и цвет текста, цвет фона и ширину контента.

Изменения применяются по кнопке «Применить». Кнопка «Сбросить» возвращает исходные настройки формы и статьи. При закрытии панели выбранные значения сохраняются.

## Запуск

```bash
npm ci
npm run start
```

## Проверки и сборка

```bash
npm run check
npm run build
```

## Компоненты в Storybook

```bash
npm run storybook
```

Сборка Storybook: `npm run build-storybook`.
